# Changelog

## 0.4.0

- First public community release as Classic DockMode.
- Compact dock status and clearer profile, test, and permission controls.
- Advanced output and rotation settings grouped together.
- Profile testing explains when an external display is required.
- Optional background detection and generic frontend selection.
- Local recovery state, disconnect restoration, and Android backup disabled.
- README setup guide, recovery instructions, and rendered UI previews.

Built on the earlier 0.3.x development versions for Retroid Pocket Classic and Dell D6000. This release has been built and checked locally; new physical dock testing remains a community task.
